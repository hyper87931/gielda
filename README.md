# NovaX Crypto Exchange (React Modular + Vite + Tailwind)

Modularna aplikacja w technologii React, Vite i Tailwind CSS podzielona na czyste komponenty i ekrany.

## Struktura projektu:
- `src/types/index.ts` - Typy i interfejsy TypeScript
- `src/components/Navbar.tsx` - Górny pasek nawigacyjny
- `src/components/CustomToast.tsx` - System powiadomień
- `src/components/MiniChart.tsx` - Wykres SVG cen
- `src/components/OrderBook.tsx` - Arkusz zleceń
- `src/screens/AuthScreen.tsx` - Ekran logowania
- `src/screens/MarketsScreen.tsx` - Ekran rynków
- `src/screens/TradeScreen.tsx` - Ekran handlu
- `src/screens/PortfolioScreen.tsx` - Ekran portfela i historii

## Uruchomienie:
```bash
npm install
npm run dev
```
